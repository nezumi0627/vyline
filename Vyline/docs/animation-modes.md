# アニメーションモード

## 方針

Vyline のモーションは CSS を中心に実装し、GPU 負荷の高い常時アニメーションや新しい依存ライブラリを増やさない。画面切替、設定セクション切替、プロフィール表示など「状態が変わったこと」を伝える短い入場モーションを基本とする。

## 3つのモード

| モード | 目的 | 挙動 |
| --- | --- | --- |
| Vyline | 標準 | 既存のポップイン・メッセージ・ドロワーに加え、画面/設定セクションを軽く表示 |
| フェザー | 低スペック端末 | 同じ視覚的な意味を保ちつつ、モーションを約90msへ短縮 |
| オフ | 動きを不要とする環境 | アニメーションとトランジションを停止 |

設定は `useStore` に永続化され、`ThemeApplier` が `html[data-animation-mode]` に反映する。アニメーションモードは通信量・ポーリング・メディア取得には影響しない。

省データモードは別機能として、アニメーション変更とは別ブランチで設計・実装する。
