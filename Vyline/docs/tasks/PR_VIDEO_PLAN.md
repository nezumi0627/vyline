# PR動画 再録画計画

## 目的

`/pr-demo` の仮データだけを使い、Vyline のUIで操作できる機能を、実際のクリック・入力・状態変化まで含めて機能別に録画する。OpenScreen の編集可能カーソルとズームを使い、全クリップを高画質60fpsで書き出す。

## 方針

- 実アカウント、実MID、実チャット、外部APIを使わない。
- 画面は横長になりすぎない録画専用比率にし、操作対象を十分な大きさで見せる。
- 各クリップは「開始状態 → 操作 → 結果」の順で完結させる。
- 設定画面を開くだけのクリップは作らず、変更結果が見える操作を必ず入れる。
- `.openscreen`、字幕、MP4、検証結果を同じシナリオIDで管理する。

## 録画品質の受け入れ条件

- [ ] 全MP4が60fps
- [ ] 全MP4がH.264、高品質書き出し
- [ ] URL文字列や壊れた画像が画面に出ない
- [ ] 各クリップに操作対象へのカーソル移動とズームがある
- [ ] 操作後の状態変化を最低1秒表示する
- [ ] 個人情報・実アカウント通信がゼロ
- [ ] シナリオ数とMP4数が一致する
