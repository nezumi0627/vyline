# プライバシーとデータの扱い

最終更新: 2026-11-02

## アカウントと利用上の注意

VylineはLINE株式会社およびLY Corporationが提供・承認するアプリではありません。LINE側の利用条件や仕様変更によって機能が制限され、アカウントに影響する可能性があります。利用は利用者自身の判断で行ってください。これは法的助言ではありません。

## 保存先

ログイン情報、セッション、暗号鍵、トーク履歴、設定、キャッシュは、ローカル環境または利用者が構成したサーバーに保存されます。外部サーバーを利用する場合は、その運営者、アクセス権、バックアップ、暗号化、保管場所を確認してください。

Windowsではセッション情報の保護にDPAPIを使う構成があります。端末認証が失効した場合など、保存済み情報があっても再ログインが必要になることがあります。詳細は[ログインフロー](../login-flow.md)を参照してください。

## AI機能と外部サービス

Agent Iの質問、文章支援、翻訳、要約などでは、利用者が入力または明示的に選択した内容がYahooのAgent Iへ送信される場合があります。AI機能は設定から無効化できます。無効化後はAI関連のボタン・処理を利用できません。送信対象は各機能の画面説明を確認してください。

## サポート用ログ

診断データは共有前に画面で確認してください。サポートZIPやログを共有する前に、認証情報、Cookie、token、暗号鍵、完全なMID、メッセージ本文が含まれていないことを確認してください。生ログを公開Issueへ貼らないでください。

## ベータ機能

ベータ機能では、通常の利用規約同意とは別に機能ごとの説明・同意を求める場合があります。保存場所や外部送信の有無は各機能の画面説明を確認してください。
