# Privacy and Data

Last updated: 2026-11-02

## Account and usage risks

Vyline is not provided or approved by LINE Corporation or LY Corporation. LINE-side terms or protocol changes may limit features or affect an account. Use it at your own discretion. This page is not legal advice.

## Where data is stored

Login information, sessions, encryption keys, chat history, settings, and caches are stored in the local environment or on a server configured by the user. Before using an external server, review its operator, access controls, backups, encryption, and data location.

Some Windows configurations protect session data with DPAPI. If device authorization expires or is revoked, you may need to log in again even when local session data remains. See the [login flow](../login-flow.md).

## AI and external services

AI features such as Agent I questions, writing assistance, translation, and summaries may send text you enter or explicitly select to Yahoo Agent I. AI features can be disabled in settings; when disabled, AI-related buttons and processing are unavailable. Check each feature's on-screen notice for the content it sends.

## Support logs

Review diagnostic data before sharing it. Before publishing a log or support archive, check that it does not contain credentials, cookies, tokens, encryption keys, full MIDs, or message bodies. Do not post raw logs in public issues.

## Beta features

A beta feature may request separate, feature-specific consent in addition to the general terms. Check the feature's description for storage and external-transfer details.
