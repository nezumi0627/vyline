# 起動コマンド

最終更新: 2026-08-24

## ⚠️ 必ずルート (e:\projects\Vyline) で実行すること

# backend + frontend 同時起動

bun run dev

# backend のみ

bun run dev:backend

# frontend のみ

bun run dev:frontend
