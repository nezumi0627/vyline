# Agent I ベータ機能

Issue #64 のベータ機能として、Yahoo の Agent I を使った文章支援を提供します。

## できること

- Agent I への質問・文章の推敲
- 明示的に選択したトークの要約
- 回答の下書きへの挿入
- 同一ベータセッション内の短い会話履歴

## データと同意

この機能は初回利用時に機能単位の同意を求めます。同意ログは端末のローカルストレージに保存します。
入力したプロンプト、明示的に選択した要約本文、短いAI会話履歴は回答生成のためYahooのAgent Iへ送信されます。
Vylineはそれらを保存・収集せず、LINEへ自動送信もしません。下書きへの挿入とLINE送信は別操作です。

匿名YahooセッションのCookieはbackendプロセスのメモリ内にのみ保持し、ディスクやVylineの外部サービスへ保存しません。
利用者は機密情報、認証情報、第三者の個人情報を入力しないでください。ベータ機能の回答は正確性を保証せず、法律・医療・金融の助言ではありません。

## API

- `POST /api/beta/agent-i/:accountId/chat`
- `GET /api/beta/agent-i/:accountId/history`
- `DELETE /api/beta/agent-i/:accountId/session`

入力サイズと履歴件数にはbackend側の上限を設けています。メッセージ履歴を自動収集する処理はありません。
