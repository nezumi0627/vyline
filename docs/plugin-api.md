# Vyline プラグイン API（予定）

> **ステータス: 予定（未実装）** — 現在の ver ではプラグイン API は非対応です。
> 下記は設計方針のメモであり、仕様は実装時に変更され得ます。

## 概要

Vyline は外部プラグインで UI や挙動を拡張できるようにする予定です。

- 読み込み方式: **ES Modules**（動的ロード）→ 再ビルド不要でプラグイン追加
- 配布: ローカルフォルダ配置 / URL 指定（将来は マーケットプレイス想定）
- 権限: プラグインごとの許可（メッセージ送信・メディア取得・テーマ変更など）を明示的に付与

## 予定される API 面

| 領域         | 内容                                                   |
| ------------ | ------------------------------------------------------ |
| UI 拡張      | サイドバー・メニュー・メッセージバブルへの拡張ポイント |
| メッセージ   | 送受信フック・フィルタ・内容変換                       |
| テーマ       | VyTheme トークンへの動的アクセス                       |
| バックエンド | plugin API ルート（BFF 経由）の登録                    |
| 通知         | 未読・着信イベントの購読                               |
