# v0 受注プロンプト — Vyline Desktop（Nezu UI）最高品質 PRO 級

> 用途: [v0.dev](https://v0.dev) / 同等の UI 生成にそのまま貼る日本語プロンプト。  
> 生成物は React + Tailwind。既存 Vyline（Bun + Hono + React + Zustand）に組み込み可能なコンポーネント単位で出すこと。

---

## プロンプト本文（ここからコピー）

あなたはプロダクトデザインとフロントエンド実装の両方に強いシニアデザイナー兼エンジニアです。  
**Vyline**（LINE 互換のサードパーティデスクトップ／タブレットクライアント）の UI/UX/レイアウトを、**PRO 級の完成度**で設計・実装してください。

目標は「公式 LINE と Telegram Desktop の良いところを取りつつ、Vyline 独自の **NezuTheme（着せ替え）** と **Home ハブ** を核にした、使いやすく美しいメセンジャー」です。  
見た目だけのダッシュボードや、カードだらけの SaaS 風レイアウトは禁止です。

### プロダクト要約

- 名称: **Vyline**
- 種別: デスクトップ優先、タブレット／大画面スマホにも耐えるレスポンシブ
- コア体験: チャット送受信、既読、スタンプ／絵文字、プロフィール、通話導線、着せ替え、プライバシー（PIN）、配信者モード
- 技術前提（生成コード）: React + TypeScript + Tailwind CSS。状態は Zustand 想定。アイコンはシンプルな SVG（絵文字アイコン乱用禁止）

### 全体情報設計（必須画面）

1. **Home（ハブ）** — 起動時・アップデート後の入口  
   - ブランド名 Vyline をヒーロー級で  
   - タイル: チャット / 設定 / NezuTheme / プライバシー  
   - アップデートノート（1回表示）  
   - 配信者モード・PIN 設定のショートカット  
2. **チャットシェル** — 左サイドバー + 右トーク  
   - サイドバー: 自分プロフィール、タブ（全体／友達／グループ／非表示）、検索、チャット行  
   - トーク: ヘッダー、メッセージ、入力、プロフィールドロワー  
3. **設定** — 既読／表示／Desktop 復元／NezuTheme 詳細／デバッグ導線  
4. **PIN ロック画面** — 4〜8 桁数字。解除までチャットへ進めない  
5. **プロフィールドロワー** — 友だち／グループ。トークを開く・音声／ビデオ・（将来）名前変更・メンバー一覧  
6. **着せ替え（NezuTheme）パネル** — プリセット＋カスタム（アクセント、背景、吹き出し色、角丸）

### レイアウト硬規則

- 最初のビューポートは **1 つのまとまった構図**（ダッシュボード化しない）
- Home では **Vyline ブランドが主役**。ナビ文言だけにしない
- カード乱用禁止。操作の入れ物として必要なときだけ面を持つ
- チャット背景はフラット単色だけにしない（微細パターン or 着せ替え背景画像）
- 紫グラデ／汎用 AI スロップ見た目を避ける。方向は次のいずれか:
  - **Telegram Night**（深い青灰 + `#2aabee`）
  - **LINE Dark**（黒 + `#06c755`）
  - **Soft Day**（明るい灰青）
- フォント: 表現力のある日本語向け（例: IBM Plex Sans JP）。Inter / Roboto / Arial / system デフォルト禁止
- モーション: 2〜3 個意図的に（ドロワー入場、絵文字ポップ、タイルホバー）。ノイズな無限アニメ禁止

### チャット UX（必須挙動の UI 表現）

- **既読**  
  - 自分のメッセージの下にだけ表示  
  - DM: 既読されたら文言「既読」（チェックマーク禁止）  
  - グループ: 「既読」+ 右に人数 `既読 3`  
  - オプション ON 時: 既読者一覧（名前 or mid）を折りたたみ or 下に小さく  
- **右クリックメニュー**  
  - 文字バブル／スタンプ／絵文字本体のみ。空白行・アバター・余白では出さない  
  - 項目: リプライ、コピー、既読にする（設定次第）、送信取り消し（自分のみ）  
- **送信取り消し**  
  - 取り消し後はイタリックで「取り消し」と表示（「空メッセージ」禁止）  
- **下書き**  
  - 入力欄はチャットごとに保持。切替後も復元されることを UI で示唆（プレースホルダ等）  
- **スタンプ／絵文字**  
  - スタンプはアニメーション可能な見た目（APNG 想定のサイズ 128）  
  - 絵文字のみメッセージは大きく、軽いポップイン  
- **メディア**  
  - 画像プレビュー、動画／音声コントロール、失敗時は控えめなフォールバック  
- **URL プレビュー**（デザイン必須・モック可）  
  - テキスト内 URL の下に OGP 風プレビュー（タイトル・説明・サムネ）。過密にしない  
- **通話**  
  - ヘッダーとプロフィールに音声／ビデオ。発信中オーバーレイはシンプル

### オリジナル機能の UI（載せ替え可能な枠）

- **NezuTheme**: LINE の着せ替え相当。プリセット切替 + カスタム（背景画像 URL、アクセント、msgIn/msgOut、半径）  
- **配信者モード**: 一覧・ヘッダーの名前を「友だち」「グループ」に伏せる。トグル一目で分かる  
- **パスコード**: 全チャット共通 PIN。ロック画面はブランド強め・余計な情報なし  
- **グループ管理（将来実装枠）**: アイコン変更、名前変更、参加者一覧、退出  
- **友だち表示名の変更（ローカルメモ名）**  
- **自分のプロフィール編集枠**: アイコン・表示名・ステータス  
- **共通パスコード＆プライバシーセンター**

### コンポーネント納品単位（v0 に分割生成してよい）

1. `HubHome`  
2. `ChatShell`（Sidebar + ChatArea）  
3. `MessageBubble`（既読・取り消し・スタンプ・絵文字・URL プレビュー）  
4. `ProfileDrawer`  
5. `NezuThemePanel`  
6. `PinLockScreen`  
7. `SettingsSections`（既読／表示／テーマ／プライバシー）

各コンポーネントは props 駆動で、ダミーデータを埋め込んでプレビュー可能にすること。

### アクセシビリティ／ユーザビリティ

- キーボード: Esc でドロワー／メニュー閉じる  
- フォーカスリングを消さない  
- コントラスト確保（Soft Day でも本文が読める）  
- タッチターゲット 40px 以上（タブレット）  
- サイドバー幅可変の余白（約 320–400px）  
- 空状態・読み込み・エラーをそれぞれ丁寧に（送信エラーは入力欄付近）

### 禁止

- 紫オン白／紫インディゴの定番 AI グラデ  
- 暖かいクリーム + テラコッタ + セリフのテンプレ  
- 新聞風の極細罫線レイアウト  
- ヒーロー上の浮遊バッジだらけ  
- 絵文字を UI アイコン代わりに多用  
- 「AI チャットボット風」の中央カラム LP

### 成果物の出し方

1. まず情報設計の短い説明（日本語 5 行以内）  
2. 画面ごとの React コンポーネント  
3. 使う CSS 変数一覧（`--vy-*`）  
4. レスポンシブのブレークポイント方針  
5. 次の実装チケット案（メンバー編集 API 接続、OGP 取得、通話 Planet 接続）を箇条書き

**品質基準:** プロダクトデザイナーがレビューしても「このまま実装チケット化できる」レベル。装飾のための装飾を避け、操作の発見可能性と視線誘導を最優先。
