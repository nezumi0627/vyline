# UI 多言語対応

Vyline Desktop は i18next / react-i18next の同梱カタログで UI を翻訳します。表示言語は「設定 → 表示」で選択でき、`システム設定` または `日本語`、`English`、`繁體中文（台灣）`、`简体中文`、`Bahasa Indonesia`、`한국어`、`Español`、`Français`、`Deutsch`、`Português (Brasil)`、`Tiếng Việt`、`ไทย` に対応します。

## 翻訳を追加する

1. JSXの静的なUI文言は `uiText("日本語の原文")` を通してください。画面ごとの動的な翻訳には `useTranslation()` の `t()` を使えます。
2. 日本語の原文をキーとして、同じキーを `src/i18n/locales/<locale>.json` に追加します。
3. 未翻訳キーは日本語へフォールバックします。キー文字列や空欄をユーザーに見せないでください。
4. UI のラベル、説明、placeholder、`aria-label`、title、toast、確認ダイアログを対象にします。
5. LINE のメッセージ、ユーザー名、プロフィール文、API / protocol 値は翻訳しません。
6. 文中に値を埋め込む場合は i18next interpolation を使い、言語ごとの語順を保てる文章にします。日付・数値は `Intl` を使います。
7. 固定幅を増やさず、長い翻訳で折り返し・スクロール・ボタン配置が崩れないことを確認します。

UI 言語設定はこの端末の IndexedDB に保存され、設定バックアップにも含まれます。旧バックアップに言語がない場合は `system` を適用します。

翻訳キー一覧は `Vyline/apps/desktop/src/i18n/source-strings.json` です。新しいUI文言を加えたら一覧と各言語カタログを更新してください。カタログはViteの動的importで選択中の言語だけを読み込みます。
