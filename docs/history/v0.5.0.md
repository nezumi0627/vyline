# v0.5.0-beta 旧版移行メモ

最終更新: 2026-11-02

このページは旧版の経緯を残すための資料です。現在の基準版はv1.0.1であり、新規導入では以下の旧版手順を使わないでください。

## v0.4.xからの主な変更

- 受信エンジンをPush長ポール方式からfetchOps方式へ変更しました。トークイベントをLINEの同期操作とrevisionカーソルで取得する設計です。
- Bearer token認証を使う公開API（/v1/）を導入しました。
- 通話、メンバー変更、既読、リアクション、アナウンスなどのイベントを追加しました。
- 旧Frontendとの互換性がなく、設定やキャッシュを作り直す場合がありました。

## 当時の更新手順

当時はソース環境でgit pull、bun install、bun run devを行う手順を案内していました。現在の導入・更新方法は[配布ガイド](../distribution.md)と[アップデートガイド](../user-guide/update.md)を参照してください。
