# Legacy Migration Note: v0.5.0-beta

Last updated: 2026-11-02

This page preserves historical context. The current baseline is v1.0.1; do not use these legacy instructions for a new installation.

## Changes from v0.4.x

- Replaced Push long-polling with fetchOps, which obtains chat events through LINE sync operations and a revision cursor.
- Introduced the Bearer-token authenticated public API under /v1/.
- Added call, member-change, read, reaction, and announcement events.
- The release was incompatible with the old frontend, and some settings or caches could require recreation.

## Upgrade instructions at the time

The old source-based instructions were git pull, bun install, and bun run dev. For current installation and update procedures, see the [Distribution Guide](../distribution.md) and [Update Guide](../user-guide/update.md).
