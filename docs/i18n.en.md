# UI localization

Vyline Desktop localizes its UI with bundled i18next / react-i18next catalogs. Choose a language in **Settings → Display**: system default, Japanese, English, Traditional Chinese (Taiwan), Simplified Chinese, Indonesian, Korean, Spanish, French, German, Brazilian Portuguese, Vietnamese, or Thai.

## Adding translations

1. Wrap static JSX copy with `uiText("Japanese source text")`. Use `t()` from `useTranslation()` for component-specific dynamic copy.
2. Use the Japanese source text as the key and add translations to `src/i18n/locales/<locale>.json`.
3. Missing entries fall back to Japanese. Never expose a raw key or a blank label.
4. Localize labels, descriptions, placeholders, accessibility labels, titles, toasts, and confirmation dialogs.
5. Do not translate LINE messages, user names, profile text, or API / protocol values.
6. Use i18next interpolation for variables so translators can change word order. Format dates and numbers with `Intl`.
7. Keep layouts fluid and verify that longer translations wrap without clipping or changing button placement.

The locale preference is stored locally in IndexedDB and included in settings backups. Older backups without a locale field restore to the system-default setting.

The key inventory is `Vyline/apps/desktop/src/i18n/source-strings.json`. When adding UI copy, update the inventory and locale catalogs. Vite dynamically imports only the selected locale catalog.
