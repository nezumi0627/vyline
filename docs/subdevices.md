# サブデバイス接続

Vyline は、PCで起動したサーバーを認証元として、同じLANに接続したiPhone・Androidのブラウザをサブデバイスとして登録できます。

## 起動

LAN公開は明示的に有効化してください。

PowerShell:

```powershell
$env:VYLINE_LAN_ACCESS = "true"
bun run dev
```

本番ビルドやDockerでは、同じ環境変数をサーバーの環境に設定します。`false`（既定）の場合、サーバーはlocalhostのみで待ち受けます。

## 接続

1. PC側のVylineを開く。
2. 設定 → サブデバイス → 「QRを表示」を選ぶ。
3. iPhone/Androidの標準カメラでQRコードを読み取る。
4. 開いたVyline画面で端末名を入力し、「この端末を接続」を選ぶ。

QRコードは2分間だけ有効で、一度登録すると無効になります。QRには長期利用できる認証情報を埋め込んでいません。

## 管理と安全性

PC側のサブデバイス一覧では、端末名・OS・最終接続時刻を確認できます。

- **削除**: 端末の現在のセッションを無効化します。後で再認証できます。
- **ブロック**: 端末のセッションを拒否し、解除されるまで再認証できなくします。
- **解除**: ブロックを解除します。

サブデバイスの認証開始はPC側のローカル画面からのみ行えます。LAN上の未認証端末から、既存のLINE APIやPC側の管理APIを直接利用することはできません。サーバーを再起動しても登録済み端末のセッション情報は `VYLINE_DATA_DIR/subdevices.json` に保存されます。

外部インターネットへの公開はこの機能の対象外です。必要な場合はCloudflare Access等の認証付きリバースプロキシを併用してください。
