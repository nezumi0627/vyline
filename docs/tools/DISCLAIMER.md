# 免責・利用目的（必読）

本リポジトリ（Vyline-Search）および付属ツールは、**教育・学習・セキュリティ研究・相互運用性の理解**を目的とした **実験用** のものです。

## 目的

- 保護機構（例: Themida）や PE / 逆コンパイル手法の学習
- 自分の環境にインストールしたクライアントの **ローカル解析実験**
- プロトコル・実装理解のためのリバースエンジニアリング練習

## 禁止・非推奨

次の用途には **使わないでください**。

- 第三者への攻撃、マルウェア解析以外での不正アクセス
- サービス利用規約・著作権法・その他法令に違反する行為
- アカウントの乗っ取り、認証の回避、不正な自動化・スパム
- 解析結果や dump の無断再配布（特に実行ファイル本体・秘密情報）

## 自己責任

- 実行・解析の結果（アカウント制限、データ破損、OS 不安定化、法的問題など）は **すべて利用者の責任** です
- 作者・貢献者は、本ツールの使用により生じた損害について **一切の責任を負いません**
- `unpack` は対象プロセスを **実際に起動・計装** します。信頼できる環境（可能なら VM）で、自分のマシン上の自分のインストールに対してのみ実行してください
- 出力（`unpacked_*.exe`、decompile 結果など）は git にコミットせず、第三者に渡さないでください
