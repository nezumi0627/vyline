# Vyline ドキュメント運用フォーマット

最終更新: 2026-08-24

## 基本形

各ドキュメントは、先頭を次の順序にする。

```md
# タイトル

最終更新: YYYY-MM-DD

概要を一段落で書く。
```

日付は内容を確認または変更した日とし、ファイルの機械的な整形だけでは更新しない。

## 用語

- `storage/saved-media/`: 送信済みまたは取得済みのメディアを保持する永続ストレージ。ユーザーが明示的に削除するまで残す。
- `storage/cache/`: CDN画像、プロフィール画像など、削除しても再取得できるデータのキャッシュ。
- 「メディアキャッシュ」は保存メディアの意味では使わない。

## 棚卸し

文書を変更する前に、参照先のファイル・API・環境変数が現存することを確認する。存在しない仕様は「未実装」または「廃止」と明記し、代替がなく参照価値もない文書は削除する。

実装変更に伴う文書は、コードと同じPRで更新する。索引から外れた文書を残さない。
