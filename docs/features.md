# Vyline 機能ガイド

最終更新: 2026-11-03

安定版 **1.1.0** を使う人向けに、各ガイドの機能案内をこのページへまとめています。
導入手順は[使い始める](./start-here.md)、実装と実LINE環境での検証状態は[機能検証表](./feature-capabilities.md)を参照してください。
この一覧の掲載は、すべての機能のライブ検証を保証するものではありません。

## アカウントと端末

- QRコード・メールアドレスによるログイン、保存済みセッションの復元、複数アカウントの切り替え。
- プロフィール表示・編集、友だち検索、ブロック状態の確認や連絡先管理。
- サブデバイスのペアリングと端末単位の利用。
- 認証の期限切れや端末認証の失効、LINE側の仕様変更によっては再ログインが必要です。

## トークとメッセージ

- DM・グループの一覧、メッセージ送受信、返信、編集、取消、再送。
- 既読・未読、グループの読者情報、リアクション。
- Letter Sealingの復号・送信と、LINE Desktopから取り込む鍵の利用。鍵は機密情報として保管してください。
- チャット内検索、正規表現検索、Ctrl+F、URL認識・コピー・プレビュー。
- 名前付きメンション、グループへの招待、グループ作成と設定。ノートやアルバムなど利用できる追加機能もあります。
- 通話機能は実験的です。LINE側の提供条件や端末による制限があります。
- OpenChat / Square は個別同意が必要な Beta です。有効化前はSquare通信を行いません。現在の対応範囲と未対応のスレッド・ノート・役職等は[OpenChat / Square Beta](./openchat-square.md)を確認してください。

## メディアと表示

- 画像・動画・音声・ファイルの送受信と表示、スタンプ、LINE絵文字。
- Flex・カルーセル・Richコンテンツの描画。
- VyTheme、文字サイズ、表示密度、プロフィール背景などの外観設定。
- 画像の自動圧縮・高画質送信、メディアの自動保存やプレビューを設定から管理できます。

## プライバシーとサポート

- ストリーマーモードの項目別マスク、PINロック、ブラウザ通知などの通知設定。
- Betaではブロック状態確認など、追加同意を必要とする機能があります。
- Agent Iによる文章支援などのAI機能は、利用規約と個別設定に従って有効・無効を切り替えます。入力内容がYahooのAgent Iへ送信される機能があります。
- 診断情報は共有前に内容を確認できます。秘密情報を含むログをそのまま公開しないでください。

## バックアップと運用

- VylineBackupによるチャット履歴・メディアのバックアップと復元。
- Snapshotの作成・一覧・復元、iOSバックアップからの履歴取り込み。
- CLIによるセットアップ、環境診断、修復。
- Dockerセルフホスト、ブラウザからの利用、Bearer token付き公開API。
- Windows・Linuxの配布版と、Apple Silicon / Intel向けのmacOSアプリZIPがあります。macOS版は未署名・未公証のため、初回起動時にGatekeeperの確認が必要です。

## 保存と移行を使い分ける

| やりたいこと | 使う機能 | 詳しい手順 |
| --- | --- | --- |
| 履歴と保存済みメディアを退避、復元する | VylineBackup。チャット選択とテキストのみの復元に対応 | [バックアップと復元](../Vyline/docs/guides/vyline-backup-restore.md) |
| 設定を別環境へ引き継ぐ | 設定引継ぎZIP。認証情報とE2EE鍵は含めない | [設定引継ぎ](./setup-account-handoff-debug.md) |
| iPhoneのローカル履歴を取り込む | 暗号化iOSバックアップからの取り込み。対応範囲に制限あり | [iOSバックアップ取り込み](../Vyline/docs/guides/ios-backup-restore.md) |
| アプリを更新する | 更新案内と配布物のダウンロード | [アップデート](./user-guide/update.md) |

## 自分の環境へ広げる

外観は[VyTheme](./user-guide/themes.md)、別端末からの利用は[サブデバイス接続](./subdevices.md)を参照してください。
外部プログラムとの連携は[公開API](./api/openapi.md)、サーバー運用は[Docker導入](./install/docker.md)と[セルフホスト](./selfhosting.md)にまとめています。
プラグインの設定画面、Backend API、自動起動は1.0.2で除去されました。[プラグイン資料](./developers/plugin-system.md)は開発者向けの旧実装資料です。現行配布版で使えるプラグインストアを案内するものではありません。

## 検証状況

LINEサーバーとの通信を必要とする機能は、コード上の実装があってもライブ環境で未確認の場合があります。実LINEで確認したか、未対応や制約があるかは[機能検証表](./feature-capabilities.md)で個別に確認してください。
