# Setup・復元体験の拡張計画

## 目的

LINE ログイン後に、既存の Vyline データを安全に復元してから利用環境を整えられる初回導線を作る。認証トークン、Cookie、E2EE 鍵、パスワード、トークンは、いかなるエクスポートにも含めない。

## 体験の流れ

1. 既存のログイン画面で LINE にログインする。
2. ローカルにある VylineBackup と、ユーザーが選ぶ設定引継ぎ ZIP を確認・復元する。
3. LINE のプロフィール名で「おかえりなさい」と歓迎する。
4. 通知、外観、保存、プライバシー、パフォーマンスを設定して開始する。

## 実装タスク

1. 引継ぎ ZIP の事前検証 API を追加し、提供元・作成日時・対象アカウント一致・対象ファイルを表示する。
2. 初回 Setup を 5 ステップへ拡張し、ローカル履歴バックアップ復元と引継ぎ ZIP を選べるようにする。
3. 詳細・復元へ VylineBackup の作成・復元・一覧・外部ファイルの入出力を追加する。
4. 設定の JSON 入出力を形式検証、サイズ制限、内容表示、失敗時の安全な中断を備えた形式に更新する。
5. ZIP 改ざん、対象アカウント不一致、復元済みバックアップ、旧 Setup 状態をテストし、文書化する。

## 互換性と安全性

- 既に Setup を完了したアカウントは再表示しない。
- 旧 3 ステップの未完了状態は、新しいステップへ継続できる。
- 引継ぎ ZIP は検証後にのみ適用し、既存設定を原子的に退避してから上書きする。
- 履歴バックアップはアカウントごとに隔離し、復元時は対象チャットとメディア有無を選べる。
- 外部ファイルはサイズ・形式・整合性を確認し、失敗時に既存データを変更しない。
